# 童言绘本工坊（4-6岁）

一个面向 4-6 岁儿童绘本阅读场景的网页原型，包含三个核心能力：

1. **一句话生成绘本**：输入一句话，自动拆解为 5 页故事内容。
2. **收集用户声音 + 语音转文本 + 声音插图**：录制声音，进行语音识别（浏览器支持时）并生成声音情绪波形图。
3. **根据绘本内容生成插图**：基于当前绘本文本在画布中生成示意插图。

## 本地运行

```bash
python3 -m http.server 8000
```

然后访问：<http://localhost:8000>

## 说明

- 当前实现为前端原型，插图和绘本生成逻辑为可视化示意。
- 若接入真实 AI 服务，可将 `app.js` 中相关函数替换为 API 调用。
